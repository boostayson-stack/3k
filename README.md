# 3K Jewelry Store

واجهة 3K تعمل محليًا دون حساب، وبعد حفظ الفاتورة تفتح رسالة واتساب جاهزة على رقم العميل لمراجعتها وإرسالها. عند دفع مبلغ صحيح بالجنيه يختلف عن إجمالي الفاتورة بأقل من جنيه، يظهر تأكيد لتسوية فرق الكسور أو الإبقاء عليه كرصيد. يمكن تشغيل خادم Flask لإدارة حسابات المستخدمين والصلاحيات ومزامنة البيانات.

## تشغيل الوضع المحلي مع الخادم

يتطلب Python 3.10 أو أحدث:

```powershell
python -m pip install -r requirements.txt
python -m backend.app create-owner --email owner@example.com
python -m backend.app
```

أدخل كلمة مرور المالك عند الطلب؛ لا تُحفظ أو تُعرض في سجل الأوامر. افتح `http://127.0.0.1:8765` على الجهاز الذي يشغّل الخادم.

لا تُرفع بيانات المتصفح تلقائيًا. بعد تسجيل الدخول، اختر تحميل بيانات الخادم أو دمج البيانات المحلية معه. تُحفظ بيانات كل حساب محليًا في مساحة منفصلة على الجهاز.

## الاستضافة والوصول من أجهزة أخرى

لم تُعَدّ استضافة خارجية في هذا المشروع. لا تعرّض خادم التطوير على الإنترنت. للوصول من أجهزة أخرى، انشر التطبيق على خادم موثوق مع HTTPS وموازن/وكيل عكسي، واجعل قاعدة البيانات على تخزين دائم. فعّل ملفات الارتباط الآمنة باستخدام `THREEK_COOKIE_SECURE=1`. في بيئة Linux يمكن تشغيل WSGI مثلًا باستخدام:

```sh
gunicorn --bind 127.0.0.1:8000 backend.app:app
```

وجّه الوكيل العكسي طلبات HTTPS إلى Gunicorn، ولا تفتح منفذ Gunicorn للعامة. لا تستخدم قاعدة SQLite على نظام ملفات شبكي متعدد الخوادم.
